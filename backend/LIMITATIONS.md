## 현재 제한사항

### 🔴 중대 제한사항 (즉시 개선 필요)

#### 1. **법령 데이터 부족** (가장 심각)

**현황:**
```
카테고리 1 (산업안전보건법령): 48개 문서
실제 필요한 법령 조문 수: 약 900개
현재 커버리지: 약 5%
```

**문제점:**
- 법령 검색 시 관련 조문을 찾지 못함
- 구체적인 안전 기준이 없는 일반 조문만 존재
- 예: "안전모 착용" 검색 → "제38조 보호구" 대신 "제84조 안전인증" 반환

**영향:**
- ❌ RAG 검색 품질 저하
- ❌ 법적 근거 제공 불완전
- ⚠️ 사용자에게 부정확한 정보 제공 위험

**우선순위:** 🔴 최우선

---

#### 2. **검색 정확도 문제**

**현황:**
- Similarity Score: 0.39 ~ 0.78 (낮은 수준)
- 음수 유사도는 해결됨 (cosine distance 적용)

**문제점:**
```
쿼리: "안전모 착용 의무"
기대: 제38조 보호구의 지급 등, 제39조 근로자의 보호구 착용
실제: 제84조 안전인증, 제20조 안전관리자
```

**원인:**
1. 데이터 부족 (카테고리 1: 48개)
2. 벡터 임베딩만 사용 (키워드 매칭 부재)
3. 청킹 전략 미최적화 (1000자 고정)

**우선순위:** 🔴 최우선

---

### 🟡 중요 제한사항 (개선 필요)

#### 3. **RAG 응답 속도**

**현황:**
- 평균 응답 시간: 2-4초
- RAG 검색 추가로 1-2초 증가

**구성:**
```
총 3-4초 = RAG 검색 (1초) + LLM 응답 (2-3초)
```

**개선 방향:**
- [ ] 캐싱 도입 (자주 묻는 질문)
- [ ] 비동기 검색
- [ ] 검색 결과 사전 필터링

**우선순위:** 🟡 중요

---

#### 4. **source_docs 정보 부족**

**현황:**
```json
{
  "source_docs": [
    {
      "title": "제84조 안전인증",
      "category": "1",
      "similarity": 0.396
    }
  ]
}
```

**문제점:**
- 법령 조항 번호만 표시 (내용 미포함)
- 어느 법령인지 불명확 (법률/시행령/시행규칙)
- 출처 URL 없음

**개선 필요:**
```json
{
  "source_docs": [
    {
      "title": "제38조 보호구의 지급 등",
      "law_name": "산업안전보건법",
      "law_type": "법률",
      "category": "1",
      "similarity": 0.85,
      "content_preview": "사업주는 근로자에게...",
      "url": "https://..."
    }
  ]
}
```

**우선순위:** 🟡 중요

### 데이터 품질 이슈

**1. 조문 내용 누락**
- 조항 제목만 있고 내용이 없는 경우
- 하위 항목 (1호, 2호 등) 누락

**2. 메타데이터 부족**
- 법령명 미표시
- 법령 유형 (법률/시행령/시행규칙) 구분 없음
- 시행일, 개정일 정보 없음

**3. 중복 및 버전 관리**
- 동일 조문의 여러 버전 혼재 가능
- 최신 개정 사항 반영 확인 필요

## 개선 계획

### Phase 1: 데이터 완성 (최우선)

**목표:** 법령 데이터 커버리지 5% → 90%+

**작업:**
1. API 파라미터 최적화
   ```python
   SEARCH_KEYWORDS = [
       "산업안전보건법", "시행령", "시행규칙",
       "안전", "보건", "작업", "설비", "기계",
       "화학물질", "건설", "제조", "근로자"
   ]
   ```

2. 카테고리별 전수 조사
   - 카테고리 1-9 각각 샘플링
   - 법령 문서 위치 파악

3. 크롤링 전략 수정
   - Pagination 완벽 구현
   - 중복 제거 강화
   - 메타데이터 보완

**예상 결과:**
- 법령 문서: 48개 → 900개+
- 검색 품질: 40% → 85%+

**소요 시간:** 2-3일

---

### Phase 2: 검색 품질 개선

**목표:** Similarity Score 0.4 → 0.8+

**작업:**
1. **하이브리드 검색 구현**
   ```python
   score = (0.7 * vector_similarity) + (0.3 * keyword_match)
   ```

2. **청킹 전략 최적화**
   - 현재: 1000자 고정
   - 개선: 조항 단위 분할 + 문맥 유지

3. **Re-ranking 도입**
   - 1차: 벡터 검색 (top 20)
   - 2차: Cross-encoder re-ranking (top 5)

**예상 결과:**
- 검색 정확도: 60% → 90%+
- 응답 시간: +0.5초

**소요 시간:** 1주

---

### Phase 3: 성능 최적화

**작업:**
1. 캐싱 도입 (Redis)
2. 비동기 처리 강화
3. DB 인덱싱 최적화

**예상 결과:**
- 응답 시간: 2.5초 → 1.5초
- 처리량: 2배 증가

**소요 시간:** 1주

**소요 시간:** 2주

## 권장 사용 방법

### ✅ 현재 상태에서 권장

**1. 일반 안전 질의응답**
```
좋음: "안전관리자의 역할은?"
좋음: "사업주의 안전 의무는?"
나쁨: "안전모 규격은?" (구체적 기준 부족)
나쁨: "발판 간격 기준은?" (세부 규칙 부족)
```

**2. 이미지 분석 + 일반 질문**
```
좋음: "이 현장의 전반적인 안전 위험은?"
좋음: "이 작업자의 보호구 착용 상태는?"
나쁨: "법령 몇 조를 위반했나?" (법령 부족)
```

**3. 문서 생성**
```
좋음: "안전점검 체크리스트 작성"
좋음: "안전교육 자료 생성"
```

### ❌ 현재 상태에서 비권장

**1. 법적 자문 대체**
- 법령 데이터 불완전
- 최신 개정 사항 미반영 가능
- 해석의 정확성 보장 불가

**2. 공식 문서 작성**
- 출처 검증 필요
- 전문가 검토 필수

**3. 실시간 의사결정**
- 응답 시간 2-4초
- 오프라인 환경 불가

### 📝 사용 시 유의사항

**면책 고지 필요:**
```
본 서비스는 산업안전보건법령 참고용이며,
최종 판단은 관할 관청 및 전문가와 상담하시기 바랍니다.
현재 법령 데이터 커버리지는 약 5%입니다.
```

**검색 결과 확인:**
```javascript
if (response.source_docs.length === 0) {
  console.warn("법령 검색 결과 없음 - AI 학습 데이터 기반 답변");
}

if (response.source_docs[0].similarity < 0.6) {
  console.warn("낮은 유사도 - 답변 정확성 재검토 필요");
}
```
